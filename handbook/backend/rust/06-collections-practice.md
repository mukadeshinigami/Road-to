## Задание 1: Подсчёт слов в тексте

### Описание

Программа принимает строку текста и выводит количество вхождений каждого слова (без учёта регистра; слова разделены пробелами).

### Требования

- Использовать `HashMap<String, u32>`: ключ — слово, значение — счётчик.
- Разбить строку на слова через `split_whitespace()`.
- Привести слова к одному регистру (например, нижнему) для подсчёта.

### Вопросы

1. Почему ключ — `String`, а не `&str`?
2. Как использовать `entry().or_insert(0)` для инкремента?

### Каркас

```rust
use std::collections::HashMap;

fn word_count(text: &str) -> HashMap<String, u32> {
    let mut map = HashMap::new();
    for word in text.split_whitespace() {
        let word = word.to_lowercase();
        *map.entry(word).or_insert(0) += 1;
    }
    map
}
```

Допишите вывод в `main`: обход `word_count("...")` и печать пар слово–количество.

## Задание 2: Телефонная книга (HashMap)

### Описание

Структура «телефонная книга»: имя → список телефонов. Добавление номера по имени, получение списка по имени.

### Требования

- `HashMap<String, Vec<String>>`: имя — ключ, значение — вектор номеров.
- Функция `add_phone(book: &mut HashMap<...>, name: &str, phone: &str)`.
- Функция `get_phones(book: &HashMap<...>, name: &str) -> Option<&Vec<String>>` или вывести номера в консоль.

### Вопросы

1. Зачем хранить `Vec<String>` для одного имени?
2. Как добавить первый номер для нового имени (чтобы не перезаписать существующий вектор)?

Подсказка: `entry(name).or_insert_with(Vec::new).push(phone.to_string())`.

Реализуйте и проверьте добавление и вывод для нескольких имён.

## Задание 3: Список покупок (Vec)

### Описание

Список покупок: добавление, удаление по индексу, вывод списка. Можно хранить `Vec<String>` и обрабатывать простые команды (add/remove/list).

### Требования

- Добавить элемент в конец.
- Удалить по индексу (например, `remove(0)` или по вводу пользователя).
- Вывести все элементы с нумерацией.

### Пример

```rust
let mut list: Vec<String> = vec![];
list.push("Milk".to_string());
list.push("Bread".to_string());
// list.remove(0);
for (i, item) in list.iter().enumerate() {
    println!("{}. {}", i + 1, item);
}
```

Расширьте до мини-меню или фиксированного набора операций в `main`.

## Задание 4: Фильтрация и трансформация

### Описание

Дан `Vec<i32>`. С помощью итераторов:
1) оставить только чётные;
2) умножить на 2;
3) собрать в новый `Vec<i32>`.

### Требования

- Использовать `iter()`, `filter`, `map`, `collect()`.
- Не изменять исходный вектор.

### Пример

```rust
let v = vec![1, 2, 3, 4, 5, 6];
let result: Vec<i32> = v.iter()
    .filter(|x| **x % 2 == 0)
    .map(|x| x * 2)
    .collect();
// result: [4, 8, 12]
```

Почему в `filter` используется `**x`? (подсказка: итератор по ссылкам)

Реализуйте и выведите `result`.

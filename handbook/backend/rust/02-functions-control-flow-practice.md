### Шаги выполнения

1. Создайте новый проект:
   ```bash
   cargo new calculator_match
   cd calculator_match
   ```

2. Начните с функции `calculate`. Какие операции нужно обработать?

3. Используйте `match` для выбора операции

### Пример решения

**src/main.rs:**

```rust
fn calculate(a: i32, b: i32, operation: char) -> Option<i32> {
    match operation {
        '+' => Some(a + b),
        '-' => Some(a - b),
        '*' => Some(a * b),
        '/' => {
            if b == 0 {
                None  // Деление на ноль
            } else {
                Some(a / b)
            }
        },
        '%' => {
            if b == 0 {
                None
            } else {
                Some(a % b)
            }
        },
        _ => None,  // Неизвестная операция
    }
}

fn main() {
    println!("10 + 5 = {:?}", calculate(10, 5, '+'));
    println!("10 - 5 = {:?}", calculate(10, 5, '-'));
    println!("10 * 5 = {:?}", calculate(10, 5, '*'));
    println!("10 / 5 = {:?}", calculate(10, 5, '/'));
    println!("10 / 0 = {:?}", calculate(10, 0, '/'));
    println!("10 ? 5 = {:?}", calculate(10, 5, '?'));
}
```

**Вывод:**
```

10 - 5 = Some(5)
10 * 5 = Some(50)
10 / 5 = Some(2)
10 / 0 = None
10 ? 5 = None
```

**Примечание:** `Option<i32>` мы изучим подробнее в блоке про Enums. Пока знайте:
- `Some(value)` — есть значение
- `None` — нет значения (ошибка)

## Задание 3: Генератор чисел Фибоначчи

### Описание

Числа Фибоначчи — это последовательность, где каждое число равно сумме двух предыдущих:
- F(0) = 0
- F(1) = 1
- F(n) = F(n-1) + F(n-2)

Создайте функцию, которая вычисляет n-е число Фибоначчи.

### Требования

- Функция принимает `u32` (номер числа)
- Возвращает `u64` (чтобы поместились большие числа)
- Используйте цикл (не рекурсию для начала)

### Вопросы для размышления

1. Какие начальные значения нужны?
2. Какой цикл использовать: `for`, `while` или `loop`?
3. Сколько итераций нужно сделать?

### Шаги выполнения

1. Создайте новый проект:
   ```bash
   cargo new fibonacci
   cd fibonacci
   ```

2. Подумайте о алгоритме:
   - Начальные значения: `a = 0`, `b = 1`
   - На каждой итерации: `next = a + b`, затем сдвигаем `a = b`, `b = next`

3. Реализуйте функцию `fibonacci`

### Пример решения (итеративный)

**src/main.rs:**

```rust
fn fibonacci(n: u32) -> u64 {
    if n == 0 {
        return 0;
    }
    if n == 1 {
        return 1;
    }
    
    let mut a = 0;
    let mut b = 1;
    
    for _ in 2..=n {
        let next = a + b;
        a = b;
        b = next;
    }
    
    b
}

fn main() {
    for i in 0..=10 {
        println!("fibonacci({}) = {}", i, fibonacci(i));
    }
}
```

**Вывод:**
```
fibonacci(0) = 0
fibonacci(1) = 1
fibonacci(2) = 1
fibonacci(3) = 2
fibonacci(4) = 3
fibonacci(5) = 5
fibonacci(6) = 8
fibonacci(7) = 13
fibonacci(8) = 21
fibonacci(9) = 34
fibonacci(10) = 55
```

### Альтернативное решение (с использованием `loop`)

```rust
fn fibonacci(n: u32) -> u64 {
    if n <= 1 {
        return n as u64;
    }
    
    let mut a = 0u64;
    let mut b = 1u64;
    let mut counter = 2;
    
    loop {
        let next = a + b;
        a = b;
        b = next;
        
        if counter >= n {
            break b;
        }
        
        counter += 1;
    }
}
```

## Задание 4: FizzBuzz

### Описание

FizzBuzz — классическая задача для программистов. Напишите программу, которая:

- Для чисел, кратных 3, выводит "Fizz"
- Для чисел, кратных 5, выводит "Buzz"
- Для чисел, кратных и 3, и 5, выводит "FizzBuzz"
- Для остальных чисел выводит само число

### Требования

- Используйте цикл `for`
- Используйте условия `if`, `else if`, `else` или `match`
- Функция должна выводить результат

### Вопросы для размышления

1. Как проверить, кратно ли число 3? А 5?
2. В каком порядке проверять условия? (Сначала "FizzBuzz" или отдельно?)
3. Можно ли использовать `match`? Как?

### Шаги выполнения

1. Создайте новый проект:
   ```bash
   cargo new fizzbuzz
   cd fizzbuzz
   ```

2. Подумайте о логике:
   - Если число делится на 15 (3 * 5) → "FizzBuzz"
   - Иначе если делится на 3 → "Fizz"
   - Иначе если делится на 5 → "Buzz"
   - Иначе → само число

3. Реализуйте функцию `fizzbuzz`

### Пример решения (с `if`)

**src/main.rs:**

```rust
fn fizzbuzz(n: u32) {
    for i in 1..=n {
        if i % 15 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{}", i);
        }
    }
}

fn main() {
    fizzbuzz(100);
}
```

**Вывод (первые 20 строк):**
```

Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
16
17
Fizz
19

```

### Альтернативное решение (с `match`)

```rust
fn fizzbuzz_match(n: u32) {
    for i in 1..=n {
        match (i % 3, i % 5) {
            (0, 0) => println!("FizzBuzz"),
            (0, _) => println!("Fizz"),
            (_, 0) => println!("Buzz"),
            (_, _) => println!("{}", i),
        }
    }
}
```

**Объяснение:** `match` проверяет кортеж `(i % 3, i % 5)`:
- `(0, 0)` — делится и на 3, и на 5
- `(0, _)` — делится только на 3
- `(_, 0)` — делится только на 5
- `(_, _)` — не делится ни на 3, ни на 5

## Частые ошибки

### Ошибка 1: Точка с запятой в выражении

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y;  // ОШИБКА! Это утверждение, возвращает ()
}
```

**Решение:** Уберите точку с запятой

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y  // Правильно: выражение
}
```

### Ошибка 2: Несовпадение типов в `if` выражении

```rust
fn example(x: i32) -> i32 {
    if x > 0 {
        5      // i32
    } else {
        "zero" // &str — ОШИБКА!
    }
}
```

**Решение:** Все ветки должны возвращать один тип

```rust
fn example(x: i32) -> i32 {
    if x > 0 {
        5
    } else {
        0  // i32
    }
}
```

### Ошибка 3: Неисчерпывающий `match`

```rust
fn example(x: i32) {
    match x {
        1 => println!("Один"),
        2 => println!("Два"),
        // ОШИБКА! Что если x = 3, 4, 5...?
    }
}
```

**Решение:** Добавьте `_` для обработки всех остальных случаев

```rust
match x {
    1 => println!("Один"),
    2 => println!("Два"),
    _ => println!("Другое"),
}
```

### Ошибка 4: Бесконечный цикл

```rust
fn main() {
    let mut x = 0;
    while x < 10 {
        println!("{}", x);
        // Забыли x += 1; — бесконечный цикл!
    }
}
```

**Решение:** Не забывайте изменять переменную условия

```rust
let mut x = 0;
while x < 10 {
    println!("{}", x);
    x += 1;  // Важно!
}
```

## Задание 1: Параллельный подсчёт суммы

### Описание

Разбить срез чисел на две половины, в двух потоках посчитать сумму каждой половины, в главном потоке сложить результаты и вывести общую сумму.

### Требования

- Использовать `thread::spawn` с move-замыканием; передать в каждый поток ссылку на свою половину (например, через разбиение среза: `v.split_at(mid)`).
- Внимание: ссылка на срез не живёт достаточно долго для потока — нужно передать владение. Вариант: передать каждому потоку `Vec<i32>` (клонировать половину) или использовать крейт с scoped threads (если разрешён).
- Простой вариант: склонировать два Vec (или части) и передать по владению в потоки, вернуть из замыкания сумму и сложить после join.

### Пример (с клонированием)

```rust
let v = vec![1, 2, 3, 4, 5, 6];
let mid = v.len() / 2;
let left = v[..mid].to_vec();
let right = v[mid..].to_vec();

let h1 = thread::spawn(move || left.iter().sum::<i32>());
let h2 = thread::spawn(move || right.iter().sum::<i32>());

let s1 = h1.join().unwrap();
let s2 = h2.join().unwrap();
println!("{}", s1 + s2);
```

Реализуйте и проверьте на небольшом векторе.

## Задание 2: Producer–consumer через каналы

### Описание

Один поток (producer) отправляет в канал числа от 1 до 10; главный поток (consumer) получает их и печатает. После отправки producer закрывает канал (drop tx); consumer выходит из цикла, когда recv вернёт Err.

### Требования

- `let (tx, rx) = mpsc::channel();`
- В потоке: цикл send(1..=10), затем выход (tx уничтожится).
- В main: цикл `while let Ok(n) = rx.recv() { println!("{}", n); }`.

### Пример

```rust
let (tx, rx) = mpsc::channel();
thread::spawn(move || {
    for i in 1..=10 {
        tx.send(i).unwrap();
    }
});

while let Ok(n) = rx.recv() {
    println!("{}", n);
}
```

Запустите и убедитесь, что вывод последовательный.

## Задание 3: Многопоточная обработка «задач» (имитация)

### Описание

Очередь задач (например, Vec чисел). Несколько потоков-воркеров берут задачу из общей очереди (Arc<Mutex<VecDeque>>), «обрабатывают» (например, sleep и возвращают удвоенное значение) и складывают результат в общий вектор результатов. Главный поток заполняет очередь, запускает воркеры, по окончании выводит результаты.

### Требования

- Очередь: `Arc<Mutex<VecDeque<i32>>>`; результаты: `Arc<Mutex<Vec<i32>>>`.
- Воркер: в цикле lock очереди, pop_front; если Some(n), разблокировать и «обработать», затем lock результатов и push.
- Условие выхода воркеров: очередь пуста (можно добавить маркер «больше не будет задач» или проверять пустоту и давать небольшую задержку).

Упрощённый вариант: фиксированное число задач, воркеры заканчивают, когда очередь пуста. Реализуйте и выведите вектор результатов.

## Задание 4: Многопоточная «обработка файлов» (имитация)

### Описание

Список имён «файлов» (Vec<&str>). Запустить N потоков; каждый поток берёт имя из общей очереди (Arc<Mutex<VecDeque>>), имитирует чтение (sleep) и печатает «Processed: name». Продолжать, пока очередь не опустеет.

### Требования

- Очередь имён: Arc<Mutex<VecDeque<String>>>.
- Потоки в цикле: lock, pop_front; если Some(name), unlock, sleep, println!; если None — break или короткий sleep и повторить.
- Главный поток заполняет очередь, запускает 2–3 воркера, join всех, выводит «Done».

Реализуйте и проверьте на 5–10 «файлах».

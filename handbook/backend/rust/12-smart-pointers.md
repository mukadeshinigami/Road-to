# Блок 12: Умные указатели (Smart Pointers)

## Цель

Понять **управление памятью** через умные указатели: Box, Rc, Arc, RefCell, базово Mutex/RwLock, трейты Deref и Drop, типичные комбинации (Rc<RefCell<T>>).

---

## 1. Box<T> — выделение в куче

`Box<T>` — владеющий указатель на значение в куче. Один владелец; при drop Box освобождает память.

```rust
let b = Box::new(42);
let list = Box::new(ListNode { val: 1, next: None });
```

Использование: рекурсивные структуры (списки, деревья), большие данные, которые не хочется копировать по стеку, возврат из функции значения неизвестного размера (например, trait object через `Box<dyn Trait>`).

---

## 2. Rc<T> — подсчёт ссылок (single-threaded)

`Rc<T>` — несколько владельцев одного значения в одной нити. Владение разделяется через клонирование `Rc` (увеличивается счётчик); значение удаляется, когда количество клонов станет 0.

```rust
use std::rc::Rc;
let a = Rc::new(String::from("shared"));
let b = Rc::clone(&a);
```

Клонирование `Rc` не клонирует данные — только увеличивает счётчик. `Rc` не реализует `Send`, поэтому не подходит для многопоточности.

---

## 3. Arc<T> — атомарный подсчёт ссылок

`Arc<T>` — то же, что Rc, но счётчик атомарный; безопасен для совместного использования из нескольких потоков. Используется с `Mutex<T>` или `RwLock<T>` для разделяемого изменяемого состояния.

```rust
use std::sync::Arc;
let a = Arc::new(42);
let b = Arc::clone(&a);
```

---

## 4. RefCell<T> — изменяемость «внутри» (interior mutability)

При неизменной ссылке на значение иногда нужно его менять (кэш, ленивая инициализация). `RefCell<T>` переносит проверки заимствований в рантайм: внутри можно получить `&T` или `&mut T` через `borrow()` / `borrow_mut()`. При нарушении правил (две изменяемых или изменяемая + неизменяемая) — паника.

```rust
use std::cell::RefCell;
let c = RefCell::new(5);
*c.borrow_mut() += 1;
```

Используется когда тип снаружи «выглядит» неизменяемым (например, только `&self`), но внутреннее состояние должно меняться.

---

## 5. Mutex<T> и RwLock<T> (кратко)

- **Mutex<T>** — эксклюзивная блокировка: один поток в момент времени может держать guard и обращаться к данным. Для многопоточного разделяемого состояния: `Arc<Mutex<T>>`.
- **RwLock<T>** — несколько читателей или один писатель. Подходит, когда чтений больше, чем записей.

Оба из `std::sync`. Guard возвращается при lock() и освобождает замок при drop.

---

## 6. Deref trait

Умные указатели часто реализуют `Deref`, чтобы к данным можно было обращаться как к `T`:

```rust
let b = Box::new(42);
assert_eq!(*b, 42);  // *b разыменовывает через Deref
```

Вызов методов: если у `T` есть метод, его можно вызывать у `Box<T>` благодаря автоматическому разыменованию (deref coercion).

---

## 7. Drop trait

Трейт с методом `drop(&mut self)` вызывается, когда значение выходит из области видимости. У Box, Rc, Arc, MutexGuard реализован свой Drop (освобождение памяти, уменьшение счётчика, снятие блокировки). Свой тип может реализовать Drop для освобождения ресурсов.

---

## 8. Комбинации: Rc<RefCell<T>>

Несколько «владельцев» плюс внутренняя изменяемость: `Rc<RefCell<T>>`. Удобно для графов, деревьев с обратными ссылками в одной нити. Для многопоточности — `Arc<Mutex<T>>` или `Arc<RwLock<T>>`.

---

## 9. Типичные ошибки

- Циклические ссылки с Rc: два значения ссылаются друг на друга через Rc — счётчик не обнулится; решают через Weak или пересмотр структуры.
- Паника в RefCell при одновременном borrow и borrow_mut или двух borrow_mut.
- Использование Rc в многопоточном коде — компилятор не даст (Rc не Send).

---

## 10. Best practices

- Box — для единственного владельца и рекурсивных структур.
- Rc/RefCell — только в однопоточном коде с разделяемым/внутренне изменяемым состоянием.
- Arc/Mutex или Arc/RwLock — для многопоточного разделяемого состояния.

---

## 11. Итоги

- Box — владение в куче; Rc — несколько владельцев в одной нити; Arc — в нескольких.
- RefCell — interior mutability с проверкой в рантайме; Mutex/RwLock — блокировки для потоков.
- Deref и Drop — разыменование и освобождение ресурсов; Rc<RefCell<T>> и Arc<Mutex<T>> — типичные комбинации.

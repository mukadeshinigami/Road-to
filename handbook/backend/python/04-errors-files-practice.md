# Блок 4: Практика — ошибки и файлы

---

## Задание 1 — безопасный `read_int(path)`

Функция читает файл по `Path`, возвращает `int` из первой непустой строки.

- Файл не найден → свой класс `InputFileMissing`
- Невалидное число → `InvalidNumberInFile` с указанием пути
- Используй `raise ... from` при оборачивании низкоуровневых ошибок

---

## Задание 2 — копирование дерева с логом

Скрипт: аргументы `src_dir`, `dst_dir` (оба `Path`).

Рекурсивно скопируй только файлы с расширением `.txt` из `src_dir` в зеркальную структуру в `dst_dir`. Ошибки чтения одного файла — залогируй (`logging`) и продолжи остальные.

---

## Задание 3 — мини JSONL

Файл **JSON Lines**: каждая строка — отдельный JSON-объект.

Напиши:

- `append_record(path: Path, obj: dict) -> None` — открыть в append, записать одну строку + `\n`, `ensure_ascii=False`
- `iter_records(path: Path) -> Iterator[dict]` — лениво читай построчно; битая строка — пропусти и увеличь счётчик ошибок (верни статистику отдельной структурой или логом)

---

## Задание 4 — atomic write

Реализуй `write_text_atomic(path: Path, content: str) -> None`:

- пиши во временный файл в том же каталоге (`path.with_suffix(path.suffix + ".tmp")` или `tempfile` в каталоге назначения)
- `Path.replace` для атомарной подмены на POSIX (для учебного уровня достаточно этого упрощения)

---

## Критерии

- Везде `encoding="utf-8"` для текста
- Ресурсы только через `with` или `Path.read_text` / `write_text`

# Блок 20: Практика — CLI приложения

## Цель практики

Собрать CLI с clap: калькулятор, grep-like поиск, утилита для JSON.

---

## Задание 1: CLI-калькулятор с аргументами

### Описание

Программа принимает аргументы: первое число, оператор (+, -, *, /), второе число. Вывести результат. Парсинг через clap (позиционные или именованные).

### Требования

- Структура Args с полями: num1, op, num2 (или подкоманды для каждой операции).
- Валидация оператора (один из четырёх символов).
- При делении на 0 — сообщение об ошибке и ненулевой код выхода.

### Пример

```rust
#[derive(Parser)]
struct Args {
    a: f64,
    op: String,
    b: f64,
}
// mycalc 2 + 3  => 5
```

Реализуйте и проверьте все операции.

---

## Задание 2: Поисковик по файлам (grep-like)

### Описание

Подпрограмма вида: `mygrep PATTERN [FILE...]`. Искать PATTERN в указанных файлах (или в stdin, если файлы не заданы). Выводить строки, содержащие подстроку (без regex — достаточно contains). Опционально: флаг -i (игнорировать регистр).

### Требования

- clap: позиционный pattern, опциональный список файлов, флаг -i.
- Чтение построчно (BufRead::lines); при совпадении — печать строки (и при желании имя файла).
- Если файлов нет — читать из stdin.

Реализуйте и проверьте на тестовом файле и через echo "text" | mygrep "text".

## Задание 3: Генератор файлов проекта (опционально)

### Описание

Подкоманда `init [DIR]`: создать в указанной директории (или в текущей) базовую структуру (например, пустой README и папку src). Аргументы через clap; создание через std::fs (create_dir_all, write).

### Требования

- Подкоманда init с опциональным путём.
- Создать директорию и 1–2 файла-заглушки.

Реализуйте минимальный вариант.

---

## Задание 4: Утилита для работы с JSON

### Описание

Читать JSON со stdin или из файла (аргумент), выводить «красивый» JSON (pretty) в stdout. Или извлекать по ключу (например, флаг -k "user.name"). Парсинг через serde_json.

### Требования

- Аргумент файла (опционально); при отсутствии — stdin.
- serde_json::from_reader и serde_json::to_string_pretty; вывод в stdout.
- Опционально: извлечение вложенного поля по строке "a.b.c" и вывод только его.

Реализуйте хотя бы чтение и pretty-print.

## Задание 1: Фильтрация и трансформация коллекций

### Описание

Дан `Vec<i32>`. С помощью итераторов: отфильтровать чётные, умножить на 3, собрать в `Vec`. Затем вычислить сумму результата через `.sum()`.

### Требования

- Одна цепочка: `iter()` → `filter` → `map` → `collect()`.
- Вторая: та же цепочка без `collect`, в конце `.sum()`.

### Пример

```rust
let v = vec![1, 2, 3, 4, 5, 6];
let transformed: Vec<i32> = v.iter()
    .filter(|x| **x % 2 == 0)
    .map(|x| x * 3)
    .collect();
let sum: i32 = v.iter().filter(|x| **x % 2 == 0).map(|x| x * 3).sum();
```

Объясните, почему в `filter` используется `**x`.

## Задание 2: Обработка «файла» построчно

### Описание

Строка с переносами строк (имитация файла). Итератор по строкам: отфильтровать пустые, обрезать пробелы, вывести первые 5 непустых строк.

### Требования

- `text.lines()` — итератор по строкам.
- `map(str::trim)`, `filter(|s| !s.is_empty())`, `take(5)`.
- Собрать в `Vec<&str>` или вывести в цикле.

### Пример

```rust
let text = "  one  \n\n  two  \nthree\n\nfour\nfive\nsix\n";
let lines: Vec<&str> = text.lines()
    .map(str::trim)
    .filter(|s| !s.is_empty())
    .take(5)
    .collect();
```

## Задание 3: Генератор последовательностей

### Описание

Итератор, генерирующий числа Фибоначчи (или арифметическую прогрессию). Реализовать тип с полями (например, `curr`, `next`) и `impl Iterator for Fib` с `Item = u64`. В `main` взять первые 10 через `.take(10).collect::<Vec<_>>()` и вывести.

### Требования

- Метод `next(&mut self) -> Option<u64>`: вернуть текущее значение и обновить состояние для следующего.
- Начальные значения Фибоначчи: 0, 1 (или 1, 1 — по договорённости).

### Каркас

```rust
struct Fib { curr: u64, next: u64 }

impl Default for Fib {
    fn default() -> Self {
        Fib { curr: 0, next: 1 }
    }
}

impl Iterator for Fib {
    type Item = u64;
    fn next(&mut self) -> Option<Self::Item> {
        let curr = self.curr;
        self.curr = self.next;
        self.next = curr + self.next;
        Some(curr)
    }
}
```

Используйте в цепочке с `take(10)`.

## Задание 4: Цепочки итераторов (method chaining)

### Описание

### Требования

- `iter()` → `filter(|w| w.len() > 3)` → `map(|w| w.to_uppercase())` → `collect::<Vec<_>>()`.
- Вывести `result.len()` и элементы.

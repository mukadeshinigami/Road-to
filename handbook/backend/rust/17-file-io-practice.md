## Задание 1: Подсчёт строк в файле

### Описание

Функция `count_lines(path: &Path) -> Result<usize, io::Error>`, которая возвращает количество строк в файле. Использовать `BufReader` и `lines()`, либо `read_to_string` и подсчёт `\n`.

### Требования

- Обработка ошибок открытия и чтения через Result.
- Пустой файл — 0 строк; каждая строка (включая последнюю без `\n`) считается.

### Пример

```rust
use std::fs::File;
use std::io::{BufRead, BufReader};
use std::path::Path;

fn count_lines(path: &Path) -> std::io::Result<usize> {
    let f = File::open(path)?;
    Ok(BufReader::new(f).lines().count())
}
```

Проверьте на существующем файле и выведите результат.

## Задание 2: Копирование файлов

### Описание

Функция `copy_file(src: &Path, dst: &Path) -> Result<u64, io::Error>`. Использовать `std::io::copy(&mut reader, &mut writer)` между открытым файлом-источником и файлом-назначением. Вернуть количество скопированных байт.

### Требования

- Открыть src для чтения, dst для записи (create); при ошибке — вернуть Err.
- Использовать буферизацию (BufReader для чтения опционально; copy уже эффективен).

### Пример

```rust
use std::io::Copy;
let mut src = File::open(src)?;
let mut dst = File::create(dst)?;
let n = std::io::copy(&mut src, &mut dst)?;
Ok(n)
```

Реализуйте и скопируйте один файл в другой, проверьте размер.

## Задание 3: Поиск файлов по расширению

### Описание

Функция `find_by_extension(dir: &Path, ext: &str) -> Result<Vec<PathBuf>, io::Error>`. Рекурсивно обойти директорию (или один уровень — по договорённости), собрать пути всех файлов с заданным расширением (сравнивать через `extension()`).

### Требования

- Использовать `read_dir`, для каждой запири проверять `file_type()` (файл/директория).
- Для директорий — рекурсивный вызов (осторожно с симлинками и циклами в реальном коде; для практики достаточно простой рекурсии).
- Сравнение расширения: `entry.path().extension() == Some(ext.as_ref())`.

Реализуйте и выведите список найденных путей для тестовой папки.

## Задание 4: Парсер CSV (упрощённый)

### Описание

Прочитать CSV-файл (без кавычек и экранирования — просто строки, разделённые запятыми). Первая строка — заголовки. Вернуть `Vec<HashMap<String, String>>`: каждая строка — маппинг имя_колонки → значение ячейки.

### Требования

- Чтение построчно (BufReader::lines).
- Разбить строку по запятой; для первой строки сохранить заголовки; для остальных собрать HashMap по заголовкам.
- Обработка ошибок: открытие файла, несовпадение числа колонок (по желанию).

### Пример формата

```text
name,age,city
Alice,30,Berlin
Bob,25,Paris
```

Результат: два элемента в Vec, у каждого ключи "name", "age", "city". Реализуйте и выведите первый ряд.

# Блок 21: Практика — Базы данных (Databases)

## Цель практики

CRUD с SQLite (sqlx), миграции, при желании — пул в async и Redis-кеш.

---

## Задание 1: CRUD-приложение с SQLite

### Описание

Простой сервис (или CLI): создать таблицу `items` (id, name, created_at). Операции: добавить запись, получить по id, список всех, обновить, удалить. Использовать sqlx с SQLite и tokio.

### Требования

- Подключение: `SqlitePool::connect("sqlite:data.db").await`.
- Миграция или ручное создание таблицы при первом запуске.
- Функции: create(name), get(id), list(), update(id, name), delete(id). Вызов из main или из простого axum API.

Реализуйте и проверьте все операции (например, через тесты или один запуск с вызовами).

---

## Задание 2: Миграции базы данных

### Описание

Оформить создание таблицы `items` как миграцию sqlx. Каталог `migrations/`, файл `YYYYMMDDHHMMSS_create_items.sql` с CREATE TABLE. В коде при старте вызывать `migrate!("./migrations").run(&pool).await`. Убедиться, что повторный запуск не падает и схема применяется один раз.

### Требования

- Команда `sqlx migrate add create_items` (или ручное имя файла).
- В main или при инициализации приложения — `sqlx::migrate!().run(&pool).await`.

Реализуйте и проверьте на чистой базе.

## Задание 3: Connection pool в async-контексте

### Описание

Интегрировать пул SQLite (или PostgreSQL) в axum: состояние приложения `AppState { pool: SqlitePool }`. Маршрут GET /items — получить список из БД и вернуть JSON. Показать, что один пул передаётся в handlers через extractor (например, State).

### Требования

- Создать пул при старте, передать в Router::with_state.
- Handler принимает State<AppState>, выполняет sqlx::query_as и возвращает Json.

Реализуйте один маршрут и проверьте через curl.

## Задание 4: Кеширование через Redis (опционально)

### Описание

Простая программа: записать в Redis ключ–значение, прочитать обратно. Использовать крейт redis с tokio или блокирующим клиентом. Показать set и get.

### Требования

- Подключение к локальному Redis (redis://127.0.0.1/).
- Команды set и get (или set_ex для TTL).
- Обработка ошибок подключения.

Реализуйте и проверьте при запущенном Redis.

## Задание 1 — Hello и имя

Напиши скрипт, который:

1. Определяет функцию `main()`.
2. Читает первый аргумент командной строки после имени скрипта (`sys.argv[1]`).
3. Печатает `Hello, <имя>!`. Если аргумента нет — печатает понятное сообщение и завершает работу с ненулевым кодом (`sys.exit(1)`).

**Проверка:**

```bash
python3 greet.py Ada
# Hello, Ada!

python3 greet.py
# (сообщение об ошибке, exit code 1)
```

## Задание 2 — Калькулятор двух чисел

Скрипт принимает три аргумента: `a`, оператор (`+`, `-`, `*`, `/`), `b` — все строки, числа преобразуй в `float`. Выведи результат или сообщение об ошибке при делении на ноль / неверном операторе.

---

## Задание 3 — Конвертер температуры

Реализуй функции:

- `celsius_to_fahrenheit(c: float) -> float`
- `fahrenheit_to_celsius(f: float) -> float`

Формулы: \( F = C \times \frac{9}{5} + 32 \), \( C = (F - 32) \times \frac{5}{9} \).

В `main()` по флагу или простому текстовому режиму (`to_f` / `to_c`) читай значение и печатай результат (достаточно `input()` для интерактива, если так проще).

---

## Задание 4 — Словарь счётчиков

Дана строка (можно захардкодить). Подсчитай, сколько раз встречается каждый символ (или каждое слово, если разобьёшь по пробелам), сохрани в `dict`, выведи пары отсортированно по ключу.

Подсказка: для символов удобен `collections.Counter`, но для тренировки попробуй сначала обычный `dict` и цикл.

## Критерии готовности

- Код разбит на функции, есть `if __name__ == "__main__":`.
- Нет «магических» ошибок: пользователь получает понятный текст при неверном вводе.
- Зависимости проекта (если появятся) живут в `venv`, не в глобальный Python без необходимости.

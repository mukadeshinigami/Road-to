# Блок 22: Практика — Веб-фреймворки (Web Frameworks)

## Цель практики

REST API для todo-list на axum, при желании — JWT, CRUD с БД, HTML с шаблонами.

---

## Задание 1: REST API для todo-list

### Описание

Сервер на axum. Модель: задача с id, title, done (bool). Хранить в памяти (Vec в State с Mutex или RwLock). Маршруты: GET /todos, POST /todos (тело Json с title), PATCH /todos/:id (переключить done), DELETE /todos/:id.

### Требования

- Состояние: struct AppState { todos: Arc<Mutex<Vec<Todo>>> } (или RwLock).
- GET — вернуть Json(list), POST — добавить, вернуть созданный Todo с id, PATCH — найти по id и обновить done, DELETE — удалить по id.
- Ответы с кодами 201 (created), 404 (not found).

Реализуйте и проверьте через curl или Postman.

---

## Задание 2: API с аутентификацией (JWT) (опционально)

### Описание

Добавить маршрут POST /login (тело: username, password). При успехе вернуть JWT. Защищённый маршрут GET /me: извлечь заголовок Authorization, проверить JWT и вернуть «текущего пользователя». Использовать крейт jsonwebtoken (или аналогичный) для подписи и верификации. Пароль для учебного кода можно хранить в конфиге или хешировать (bcrypt).

### Требования

- Генерация токена с expiry; проверка в middleware или в extractor.
- При невалидном/отсутствующем токене — 401.

Реализуйте минимальный login и один защищённый маршрут.

---

## Задание 3: CRUD с базой данных

### Описание

Тот же todo-list, но данные в SQLite через sqlx. При старте приложения — миграция и пул в State. GET/POST/PATCH/DELETE работают с таблицей todos.

### Требования

- AppState с SqlitePool; в handlers — запросы sqlx (query_as, execute).
- Структура Todo с полями id, title, done (и при необходимости created_at).

Реализуйте и проверьте персистентность (перезапуск сервера сохраняет данные).

---

## Задание 4: HTML-сервер с шаблонами (опционально)

### Описание

Маршрут GET / отдаёт HTML-страницу со списком задач (или одной статичной страницей). Использовать askama или tera: шаблон с циклом по todos, подставленный из State или из БД.

### Требования

- Один шаблон (например, list.html) с переменной todos.
- В handler — загрузка данных и рендер; ответ с Content-Type text/html.

Реализуйте и откройте в браузере.

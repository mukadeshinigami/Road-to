### Пример решения

**src/main.rs:**

```rust

    println!("Взял владение: {}", s);
}  // s выходит из области видимости, память освобождается

    println!("Получил: {}", s);
    s  // Возвращаем владение обратно

    take_string(s1);
    // println!("{}", s1);  // ОШИБКА! s1 больше не валидна

    let s3 = return_string(s2);
    println!("Вернули: {}", s3);  // OK — владение вернулось
}
```

**Вывод:**
```

Вернули: world
```

### Пример решения

**src/main.rs:**

```rust

    s.len()
}  // s выходит из области видимости, но ничего не освобождается

fn append_text(s: &mut String, text: &str) {
    s.push_str(text);
}

fn main() {
    let s1 = String::from("hello");
    let len = calculate_length(&s1);
    println!("Длина '{}' равна {}", s1, len);  // s1 всё ещё валидна!
    
    let mut s2 = String::from("hello");
    append_text(&mut s2, ", world");
    println!("{}", s2);  // "hello, world"
    
    // Можно иметь несколько неизменяемых ссылок
    let s3 = String::from("test");
    let r1 = &s3;
    let r2 = &s3;
    println!("{}, {}", r1, r2);  // OK
}
```

**Вывод:**
```

hello, world
test, test
```

### Описание

### Пример решения

**src/main.rs:**

```rust
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    
    &s[..]  // Если пробела нет, возвращаем всю строку
}

fn last_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    let mut last_space = s.len();
    
    for (i, &item) in bytes.iter().enumerate().rev() {
        if item == b' ' {
            return &s[i + 1..];
        }
    }
    
    &s[..]  // Если пробела нет, возвращаем всю строку
}

fn main() {
    let s = String::from("hello world");
    
    let first = first_word(&s);
    println!("Первое слово: {}", first);  // "hello"
    
    let last = last_word(&s);
    println!("Последнее слово: {}", last);  // "world"
    
    // s всё ещё валидна!
    println!("Вся строка: {}", s);
}
```

## Задание 4: Поиск первого слова в строке

### Описание

Создайте функцию, которая находит и возвращает первое слово в строке, используя слайсы.

### Требования

- Функция принимает `&str` (чтобы работать и с `String`, и с `&str`)
- Возвращает `&str` — слайс первого слова
- Обрабатывает случай, когда пробела нет (возвращает всю строку)
- Обрабатывает случай с несколькими пробелами подряд

### Вопросы для размышления

1. Как найти позицию первого пробела?
2. Как создать слайс от начала до пробела?
3. Что делать, если пробела нет?

### Шаги выполнения

1. Создайте новый проект:
   ```bash
   cargo new first_word
   cd first_word
   ```

2. Подумайте о алгоритме:
   - Пройти по байтам строки
   - Найти первый пробел
   - Вернуть слайс от начала до пробела

3. Реализуйте функцию `first_word`

### Пример решения

**src/main.rs:**

```rust
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    
    // Ищем первый пробел
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    
    // Если пробела нет, возвращаем всю строку
    &s[..]
}

fn main() {
    let s1 = String::from("hello world");
    let word1 = first_word(&s1);
    println!("Первое слово в '{}': '{}'", s1, word1);
    
    let s2 = "rust programming";
    let word2 = first_word(s2);
    println!("Первое слово в '{}': '{}'", s2, word2);
    
    let s3 = "norust";
    let word3 = first_word(s3);
    println!("Первое слово в '{}': '{}'", s3, word3);
    
    // s1 всё ещё валидна!
    println!("Исходная строка: {}", s1);
}
```

**Вывод:**
```
Первое слово в 'hello world': 'hello'
Первое слово в 'rust programming': 'rust'
Первое слово в 'norust': 'norust'
Исходная строка: hello world
```

### Улучшенная версия с использованием методов

```rust
fn first_word(s: &str) -> &str {
    s.split_whitespace()
        .next()
        .unwrap_or("")
}

fn main() {
    let s = String::from("hello world");
    let word = first_word(&s);
    println!("Первое слово: {}", word);
}
```

**Примечание:** `split_whitespace()` разбивает строку по пробелам и возвращает итератор. `next()` берёт первый элемент, `unwrap_or("")` возвращает пустую строку, если слова нет.

## Частые ошибки

### Ошибка 1: Use after move

```rust
let s = String::from("hello");
let s2 = s;
println!("{}", s);  // ОШИБКА: value moved
```

**Решение:** Используйте ссылку `&s` или верните владение обратно.

### Ошибка 2: Cannot borrow as mutable

```rust
let s = String::from("hello");
let r = &mut s;  // ОШИБКА: s не mut
```

**Решение:** Объявите переменную как `mut`: `let mut s = ...`

### Ошибка 3: Multiple mutable borrows

```rust
let mut s = String::from("hello");
let r1 = &mut s;
let r2 = &mut s;  // ОШИБКА: два изменяемых заимствования
```

**Решение:** Используйте ссылки в разных областях видимости:

```rust
let mut s = String::from("hello");
{
    let r1 = &mut s;
    // работа с r1
}
let r2 = &mut s;  // OK — r1 уже вышел из области видимости
```

### Ошибка 4: Dangling reference

```rust
fn dangle() -> &String {
    let s = String::from("hello");
    &s  // ОШИБКА: s выйдет из области видимости
}
```

**Решение:** Верните владение, а не ссылку:

```rust
fn no_dangle() -> String {
    let s = String::from("hello");
    s  // Передаём владение
}
```

### Ошибка 5: Индекс за пределами слайса

```rust
let s = String::from("hello");
let slice = &s[0..10];  // ОШИБКА: индекс за пределами
```

**Решение:** Проверьте длину перед созданием слайса или используйте методы, которые безопасно обрабатывают это.

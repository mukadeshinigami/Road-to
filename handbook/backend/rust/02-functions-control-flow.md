## 1. Определение функций: `fn`

### Что такое функция?

Функция — это блок кода, который можно вызывать многократно. Функции помогают:
- Организовать код
- Избежать дублирования
- Упростить тестирование

### Базовый синтаксис

```rust
fn function_name() {
    // Тело функции
}
```

**Пример:**

```rust
fn greet() {
    println!("Hello, Rust!");
}

fn main() {
    greet(); // Вызов функции
    greet(); // Можно вызвать снова
}
```

**Вывод:**
```
Hello, Rust!
Hello, Rust!
```

## 2. Параметры и возвращаемые значения

### Функции с параметрами

Параметры позволяют передавать данные в функцию:

```rust
fn greet(name: &str) {
    println!("Hello, {}!", name);
}

fn main() {
    greet("Alice");
    greet("Bob");
}
```

**Синтаксис:**
- `name: &str` — параметр типа `&str` (строковый срез)
- Пока не волнуйтесь о `&` — это заимствование, изучим в следующем блоке

### Функции с несколькими параметрами

```rust
fn add(x: i32, y: i32) {
    let sum = x + y;
    println!("{} + {} = {}", x, y, sum);
}

fn main() {
    add(5, 3);
    add(10, 20);
}
```

### Возвращаемые значения

Функции могут возвращать значения. В Rust есть два способа:

#### Способ 1: Явный `return`

```rust
fn add(x: i32, y: i32) -> i32 {
    return x + y;
}
```

#### Способ 2: Неявный возврат (выражение без точки с запятой)

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y  // Нет точки с запятой — это выражение, которое возвращается
}
```

**Важно:** Обратите внимание на разницу:
- `x + y;` — это утверждение (statement), ничего не возвращает
- `x + y` — это выражение (expression), возвращает значение

### Пример использования возвращаемого значения

```rust
fn multiply(x: i32, y: i32) -> i32 {
    x * y  // Возвращаем произведение
}

fn main() {
    let result = multiply(5, 6);
    println!("5 * 6 = {}", result);
    
    // Можно использовать сразу
    println!("10 * 3 = {}", multiply(10, 3));
}
```

### Вопрос для размышления

Почему в Rust можно не писать `return`? Что произойдёт, если поставить точку с запятой после `x + y`?

## 3. Выражения vs утверждения (Expressions vs Statements)

Это **ключевая концепция** Rust, которая отличает его от многих других языков.

### Утверждения (Statements)

Утверждения выполняют действие, но **не возвращают значение**:

```rust
let x = 5;        // Утверждение: присваивание
println!("Hi");   // Утверждение: вызов макроса
x + 1;            // Утверждение: вычисление, но результат игнорируется
```

### Выражения (Expressions)

Выражения **возвращают значение**:

```rust
5                  // Выражение: возвращает 5
x + 1              // Выражение: возвращает результат
{
    let y = 3;
    y + 1          // Блок тоже может быть выражением!
}
```

### Блок как выражение

В Rust блок `{}` может быть выражением:

```rust
fn main() {
    let x = {
        let y = 3;
        y + 1  // Это выражение — возвращает значение
    };
    
    println!("x = {}", x); // x = 4
}
```

**Что произойдёт, если добавить точку с запятой?**

```rust
let x = {
    let y = 3;
    y + 1;  // Теперь это утверждение — возвращает ()
};
// x будет иметь тип () (unit type)
```

### Практический пример

```rust
fn calculate(x: i32) -> i32 {
    if x > 0 {
        x * 2  // Выражение
    } else {
        x + 10 // Выражение
    }
    // Вся функция — это выражение
}

fn main() {
    let result = calculate(5);
    println!("result = {}", result); // 10
}
```

Попробуйте написать функцию, которая возвращает большее из двух чисел. Какой синтаксис вы используете — с `return` или без?

## 4. Условия: `if`, `else if`, `else`

### Базовый `if`

```rust
fn main() {
    let number = 7;
    
    if number < 5 {
        println!("Число меньше 5");
    }
}
```

### `if` с `else`

```rust
fn main() {
    let number = 7;
    
    if number < 5 {
        println!("Число меньше 5");
    } else {
        println!("Число больше или равно 5");
    }
}
```

### `if` с `else if`

```rust
fn main() {
    let number = 7;
    
    if number < 5 {
        println!("Число меньше 5");
    } else if number < 10 {
        println!("Число между 5 и 10");
    } else {
        println!("Число больше или равно 10");
    }
}
```

### Условие должно быть `bool`

В Rust условие **обязательно** должно быть типа `bool`:

```rust
fn main() {
    let number = 3;
    
    // if number {  // ОШИБКА! number — это i32, не bool
    //     println!("Это не сработает");
    // }
    
    if number != 0 {  // Правильно: явное сравнение
        println!("Число не равно нулю");
    }
}
```

**Сравнение с другими языками:**
- В C/C++/JavaScript: `if (number)` — работает (truthy/falsy)
- В Rust: `if number != 0` — нужно явное сравнение

## 5. `if` как выражение

В Rust `if` может быть **выражением**, то есть возвращать значение:

```rust
fn main() {
    let condition = true;
    let number = if condition {
        5  // Выражение
    } else {
        6  // Выражение
    };
    
    println!("number = {}", number); // 5
}
```

### Важно: все ветки должны возвращать один тип

```rust
fn main() {
    let condition = true;
    let number = if condition {
        5      // i32
    } else {
        "six"  // ОШИБКА! Разные типы: i32 и &str
    };
}
```

**Правильно:**

```rust
fn main() {
    let condition = true;
    let number = if condition {
        5   // i32
    } else {
        6   // i32
    };
}
```

### Практический пример: функция `max`

```rust
fn max(a: i32, b: i32) -> i32 {
    if a > b {
        a
    } else {
        b
    }
}

fn main() {
    println!("max(5, 3) = {}", max(5, 3));
    println!("max(2, 8) = {}", max(2, 8));
}
```

### Вопрос для размышления

Как бы вы написали функцию, которая возвращает абсолютное значение числа? Используйте `if` как выражение.

## 6. Циклы: `loop`, `while`, `for`

### `loop` — бесконечный цикл

`loop` создаёт бесконечный цикл, который можно прервать с помощью `break`:

```rust
fn main() {
    let mut counter = 0;
    
    loop {
        println!("counter = {}", counter);
        counter += 1;
        
        if counter >= 5 {
            break;  // Выход из цикла
        }
    }
}
```

### `loop` может возвращать значение

```rust
fn main() {
    let mut counter = 0;
    
    let result = loop {
        counter += 1;
        
        if counter == 10 {
            break counter * 2;  // Возвращаем значение из loop
        }
    };
    
    println!("result = {}", result); // 20
}
```

### `while` — цикл с условием

```rust
fn main() {
    let mut number = 3;
    
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    
    println!("LIFTOFF!!!");
}
```

**Вывод:**
```
3!
2!
1!
LIFTOFF!!!
```

### `for` — итерация по коллекции

`for` используется для итерации по диапазонам или коллекциям:

```rust
fn main() {
    // Итерация по диапазону
    for number in 1..=5 {  // 1..=5 включает 5
        println!("{}", number);
    }
    
    // Итерация по массиву
    let arr = [10, 20, 30, 40, 50];
    for element in arr {
        println!("{}", element);
    }
}
```

**Диапазоны:**
- `1..5` — от 1 до 4 (не включает 5)
- `1..=5` — от 1 до 5 (включает 5)
- `..5` — от начала до 4
- `1..` — от 1 до бесконечности (осторожно!)

### Сравнение циклов

```rust
fn main() {
    // loop — когда нужен бесконечный цикл или возврат значения
    let mut i = 0;
    loop {
        if i >= 5 { break; }
        println!("loop: {}", i);
        i += 1;
    }
    
    // while — когда условие может измениться
    let mut j = 0;
    while j < 5 {
        println!("while: {}", j);
        j += 1;
    }
    
    // for — когда итерируемся по коллекции
    for k in 0..5 {
        println!("for: {}", k);
    }
}
```

## 7. `break` и `continue`

### `break` — выход из цикла

```rust
fn main() {
    let mut counter = 0;
    
    loop {
        counter += 1;
        
        if counter == 5 {
            break;  // Выходим из цикла
        }
        
        println!("counter = {}", counter);
    }
    
    println!("После цикла");
}
```

### `break` с меткой (для вложенных циклов)

```rust
fn main() {
    'outer: loop {
        let mut inner = 0;
        
        loop {
            inner += 1;
            if inner == 3 {
                break 'outer;  // Выходим из внешнего цикла
            }
        }
    }
}
```

### `continue` — переход к следующей итерации

```rust
fn main() {
    for number in 1..=10 {
        if number % 2 == 0 {
            continue;  // Пропускаем чётные числа
        }
        println!("{}", number);  // Выведет только нечётные
    }
}
```

**Вывод:**
```
1
3
5
7
9
```

### Практический пример: поиск первого чётного числа

```rust
fn main() {
    let numbers = [1, 3, 5, 8, 9, 11];
    
    for num in numbers {
        if num % 2 == 0 {
            println!("Найдено первое чётное число: {}", num);
            break;
        }
    }
}
```

## 8. `match` выражение (базово)

`match` — это мощный инструмент для сопоставления с образцом (pattern matching). Мы изучим его подробнее в блоке про Enums, но начнём с базового использования.

### Базовый синтаксис

```rust
fn main() {
    let number = 3;
    
    match number {
        1 => println!("Один"),
        2 => println!("Два"),
        3 => println!("Три"),
        _ => println!("Другое число"),  // _ — это "всё остальное"
    }
}
```

### `match` как выражение

`match` может возвращать значение:

```rust
fn main() {
    let number = 3;
    
    let word = match number {
        1 => "один",
        2 => "два",
        3 => "три",
        _ => "другое",
    };
    
    println!("{}", word); // "три"
}
```

### Несколько значений в одной ветке

```rust
fn main() {
    let number = 2;
    
    match number {
        1 | 2 => println!("Один или два"),
        3 | 4 => println!("Три или четыре"),
        _ => println!("Другое"),
    }
}
```

### Диапазоны в `match`

```rust
fn main() {
    let number = 42;
    
    match number {
        1..=10 => println!("От 1 до 10"),
        11..=50 => println!("От 11 до 50"),
        _ => println!("Больше 50 или меньше 1"),
    }
}
```

### `match` должен быть исчерпывающим

В Rust `match` должен обрабатывать **все возможные случаи**:

```rust
fn main() {
    let number = 5;
    
    match number {
        1 => println!("Один"),
        2 => println!("Два"),
        // ОШИБКА! Что если number = 3, 4, 5...?
    }
}
```

**Решение:** Добавить `_` (catch-all):

```rust
match number {
    1 => println!("Один"),
    2 => println!("Два"),
    _ => println!("Другое"),  // Обрабатывает все остальные случаи
}
```

### Вопрос для размышления

Как бы вы использовали `match` для определения, является ли число положительным, отрицательным или нулём?

## 9. `return` — явный и неявный

### Явный `return`

```rust
fn add(x: i32, y: i32) -> i32 {
    return x + y;
}
```

### Неявный возврат (рекомендуемый стиль)

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y  // Нет точки с запятой — это выражение
}
```

### Когда использовать `return`?

Обычно `return` используется для **раннего выхода** из функции:

```rust
fn divide(a: i32, b: i32) -> Option<i32> {
    if b == 0 {
        return None;  // Ранний выход
    }
    
    Some(a / b)  // Обычный возврат
}
```

**Примечание:** `Option<i32>` мы изучим в блоке про Enums. Пока просто знайте, что это способ представить "может быть значение, а может быть ничего".

### Множественные `return`

```rust
fn check_number(x: i32) -> &'static str {
    if x < 0 {
        return "Отрицательное";
    }
    
    if x == 0 {
        return "Ноль";
    }
    
    "Положительное"  // Последний возврат без return
}
```

### Вопрос для размышления

В каких случаях явный `return` делает код более читаемым? А когда лучше использовать неявный возврат?

## 10. Практические примеры

### Пример 1: Функция для проверки чётности

```rust
fn is_even(n: i32) -> bool {
    n % 2 == 0
}

fn main() {
    println!("{}", is_even(4));  // true
    println!("{}", is_even(5));  // false
}
```

### Пример 2: Функция для вычисления факториала

```rust
fn factorial(n: u32) -> u32 {
    if n == 0 || n == 1 {
        1
    } else {
        n * factorial(n - 1)  // Рекурсия
    }
}

fn main() {
    println!("factorial(5) = {}", factorial(5)); // 120
}
```
